HLEBUSHEK INJECTOR — один exe, который сам устанавливает DLL в игру; в игре появляется меню с читами

ЧТО ПОЛУЧАЕТСЯ
  bin\Hlebushek_Injector.exe — один файл. DLL с меню вшита внутрь него.
  Запустил → он находит Dizzy.exe (или сам запускает игру из соседней папки), кладёт hlebushek_menu.dll
  в папку игры, загружает её в процесс — и в игре появляется окно «Хлебушек — Mod Menu».
  Выгрузить и удалить DLL:  Hlebushek_Injector.exe --eject

КАК СОБРАТЬ (нужна 32-битная сборка, потому что Dizzy.exe — 32-битный)
  Вариант 1, без установки компиляторов: залей эту папку в репозиторий на GitHub → Actions → Run workflow →
            скачай артефакт Hlebushek_Injector.exe (файл .github/workflows/build.yml уже готов).
  Вариант 2, MinGW-w64: MSYS2 → консоль "MSYS2 MINGW32" → pacman -S mingw-w64-i686-gcc → запусти build.bat.
  Вариант 3, Visual Studio: "x86 Native Tools Command Prompt for VS" → build.bat.

КАК ПОЛЬЗОВАТЬСЯ
  1. Положи Hlebushek_Injector.exe куда угодно (лучше рядом с игрой) и запусти (при ошибке доступа — от админа).
  2. В игре: Insert — показать/скрыть меню, F1 — заморозить/разморозить всё из таблицы.

МЕНЮ
  Читы       — слоты «Жизни», «Энергия», «Очки». Введи значение, которое сейчас в игре → «Найти» → измени его
               в игре (потеряй жизнь / подбери монету) → введи новое → «Найти». Когда адрес найден, он привяжется
               сам. Поставь «Держать значение» — число будет постоянно записываться в игру (бесконечные жизни,
               энергия 100, очки).
  Сканер     — свободный поиск любых значений (int32 / int16 / byte / float), режимы равно / изменилось /
               не изменилось / увеличилось / уменьшилось.
  Таблица    — все найденные адреса: записать, заморозить, сохранить/загрузить (Hlebushek_cheats.txt).
  Окно игры  — поверх всех окон, прозрачность, открыть папку игры, выгрузить меню.

ЗАМЕЧАНИЯ
  * Только для одиночной игры и твоей собственной сборки. Адреса в куче меняются при каждом запуске игры —
    находи их заново (это быстро, 3–4 нажатия).
  * Антивирус может ругаться на любой инжектор (LoadLibrary через CreateRemoteThread) — добавь файл в исключения.
  * Меню — отдельное окно поверх игры, а не рисунок внутри её картинки: работает в оконном режиме и в F11-окне,
    в эксклюзивном полном экране может не отображаться.
  * Этот проект не компилировался в среде, где я его писал (там нет Windows-компилятора): код проверен на
    синтаксис, но первую сборку и запуск стоит проверить у себя.
